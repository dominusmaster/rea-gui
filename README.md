# REA Studio

A local browser GUI for [REA: Reverse Engineer Anything](https://github.com/morluto/rea).
Open any app and see what's inside, without executing it.

The package lives in [`rea-gui/`](rea-gui/). Brand assets (icon, logos, social preview)
are in [`rea-gui/brand/`](rea-gui/brand/).

```bash
npx rea-gui
```
